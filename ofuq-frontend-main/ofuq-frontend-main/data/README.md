# بيانات الكتالوج التجريبية

- `programs.json`: ستة برامج تعليمية، لكل برنامج مقرران.
- `courses.json`: اثنا عشر مقررًا، مع بيانات المحاضر والسعر والمدة.
- `sections.json`: الأقسام المرتبطة بالبرامج والمقررات.

كل الأسماء والأعداد والأسعار بيانات وهمية للعرض. يرتبط كل مقرر ببرنامج من خلال `category_id`، وبقسم من خلال `section_id`. معرفات العناصر يجب أن تكون فريدة.

لتفعيل الملفات في بيئة التطوير، أضف إلى `.env.local`:

```env
NEXT_PUBLIC_USE_LOCAL_CATALOG=true
```

أعد تشغيل خادم التطوير بعد تغيير الإعداد. لتوصيل الكتالوج بالخادم الحقيقي، غيّر القيمة إلى `false`. البيانات المحلية لا تستخدم في نسخة الإنتاج، ولا تنفّذ تسجيلًا أو شراءً أو عمليات إدارة.

للدخول المباشر إلى اللوحات في النسخة المحلية بدون تسجيل:

```env
NEXT_PUBLIC_LOCAL_PREVIEW=true
NEXT_PUBLIC_DEMO_MODE=true
```

تفتح اللوحات ببيانات عرض محلية بدون إصدار توكن أو إنشاء جلسة على الخادم. وضع الدخول المباشر متاح في التطوير فقط. لتعطيله أعد القيم إلى `false` وأعد تشغيل خادم التطوير.
