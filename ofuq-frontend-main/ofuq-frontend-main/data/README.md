# بيانات التجربة المحلية

- `programs.json`: 6 برامج تعليمية.
- `courses.json`: 12 مقررًا، بفصلين و4 دروس لكل مقرر؛ تشمل المحتوى والأنشطة والصور المحلية.
- `sections.json`: الأقسام.
- `experience.json`: الطلاب والإدارة والمحاضرون وأسئلة الاختبار. `answer` هو فهرس الإجابة الصحيحة بدءًا من صفر، و`course_id` اختياري لتخصيص السؤال لمقرر.
- `settings.json`: سياسة الخصوصية والشروط القابلتان للتعديل من الإدارة.

ترتبط المقررات بالبرامج عبر `category_id`، وبالأقسام عبر `section_id`، وبالمحاضرين عبر `instructor_id`. حافظ على فرادة المعرّفات وروابط البرامج المختصرة. محتوى الدروس نص عادي.

هذه البيانات هي الحالة الأولية في التطوير والإنتاج؛ لا توجد أعلام بيئة لتفعيل باك إند. بعدها تُحفظ تعديلات المستخدم في المتصفح. لتجربة تعديل ملفات JSON بعد وجود بيانات محفوظة، استخدم «إعادة ضبط التجربة» من أدوات النسخ الاحتياطي في لوحة الإدارة، بعد تصدير التعديلات التي تحتاجها.

الطالب الأساسي: سارة أحمد محمد (`99001`). الإدارة الأساسية: `99002`. هذان الحسابان لا يمكن حذفهما؛ يمكن تعديل بياناتهما. الطالب مسجل مبدئيًا بالمقررين `2001` و`2002`. بقية المقررات متاحة للتسجيل من الكتالوج.

رقم الشهادة المبدئية: `DEMO-2026-001`. شهادات الاختبارات الجديدة لها أرقام فريدة قابلة للتحقق داخل نفس المتصفح. تنشأ ملفات PDF داخل المتصفح، ولا تحتاج خدمة توليد أو مسار ملفات على الخادم.
