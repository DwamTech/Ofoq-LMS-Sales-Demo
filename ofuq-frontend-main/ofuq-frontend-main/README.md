# منصتك التعليمية — تجربة فرونت مستقلة

مشروع Next.js يعمل ببيانات JSON محلية، بدون API خارجي أو حسابات باك إند، في التطوير والإنتاج.

## التشغيل

```bash
npm install
npm run dev
```

الموقع: `http://127.0.0.1:3004`. الطالب: `/user`. الإدارة: `/admin`. اختيار اللوحة: `/experience`. الدخول مباشر بدون تسجيل. لا تحتاج ملف `.env.local` أو أي بيانات اتصال بخادم.

لبناء وتشغيل نسخة الإنتاج:

```bash
npm run build
npm start
```

## البيانات والوظائف

البيانات الأولية في مجلد `data`: 6 برامج، 12 مقررًا، 48 درسًا بمحتوى وأنشطة، أقسام ومحاضرون وطلاب وأسئلة اختيار من متعدد وسياسات الموقع. التفاصيل في [دليل البيانات](data/README.md).

يمكن للطالب التسجيل في البرامج والمقررات، إضافة المفضلة، إكمال الدروس، تقديم الاختبار وحفظ النتيجة، معاينة الشهادة وتنزيلها PDF والتحقق من رقمها، وتعديل الملف الشخصي. درجة النجاح 60٪؛ اجتياز مقررات البرنامج يصدر شهادة دبلومة.

لوحة الإدارة توفر أدوات إضافة وتعديل وحذف البرامج والمقررات والفصول والدروس والمحاضرين والطلاب والمشرفين وأسئلة الاختبارات، وإصدار الشهادات، وتحرير السياسات، ومتابعة التقارير المحلية. افتح «أدوات الإدارة» داخل الوحدة المطلوبة.

تُحفظ التعديلات في `localStorage` تحت المفتاح `mansatak-frontend-v1`، وتظهر في نفس المتصفح بعد إعادة تحميل الصفحة. من `/admin/database-backups` يمكن تصدير JSON واستيراده أو إعادة البيانات الأصلية. البيانات خاصة بالمتصفح وعنوان الموقع؛ لا تتم مزامنة بين الأجهزة.

رقم شهادة جاهزة للتجربة: **DEMO-2026-001** في `/verify-certificate`. الشهادات والأسعار بيانات تجريبية، ولا يتم تحصيل مدفوعات أو إرسال بريد أو رفع وسائط إلى خدمة خارجية. إعداد كلمة المرور نموذج تحقق محلي؛ الدخول إلى اللوحات مباشر.

`lib/frontendStore.ts` هو مصدر الحالة المشتركة. `lib/frontendAdapter.ts` يوفر توافق خدمات الواجهة القديمة مع الحالة المحلية عبر Axios Adapter، دون طلبات شبكة أو تحويل للخادم عند الفشل. البيانات غير الموجودة تعيد خطأ محليًا.
