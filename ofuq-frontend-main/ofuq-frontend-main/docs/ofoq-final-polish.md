# أُفُق — تقرير الإنهاء الإبداعي واتساق تجربة الأعمال

تاريخ التنفيذ: 10 أكتوبر 2026. النطاق: الصفحات العامة فقط. لا ترحيلات، ولا seeders، ولا تعديلات مقصودة على قاعدة البيانات أو منطق Laravel أو التسجيل أو الدفع أو لوحات المستخدم والإدارة.

## A — ملخص التصحيحات

استُبقيت هوية «المعرفة تتّسع». أصبحت صفحة المقرر ذات عنوان واضح ومسار تنقل ومنهج قابل للطي ولوحة تسجيل سياقية. نُقّحت تفاصيل الدبلومة والكتالوج، وأُضيفت رسومات SVG أصلية مرتبطة بالموضوع. استُخدمت إرشادات Sites لترتيب العرض والتحقق المحلي، دون إنشاء استضافة أو استبدال بنية Next.js.

## B — العيوب المؤكدة مقابل آثار اللقطات

عيوب مؤكدة: أوصاف تكشف أسماء بيانات التطوير؛ مزايا استرداد واعتماد غير موثقة؛ فيديو عينة يحل محل مصدر غير موجود؛ زر تعلم يؤدي إلى تفاصيل مقرر؛ تنسيق قديم يتغلب على التنسيق العام؛ تنسيق الدبلومة مرتبط بحالة التحميل دون المحتوى الحقيقي. عولجت داخل النطاق العام.

المساحة الطويلة في لقطة الصفحة الرئيسية الكاملة مرتبطة بقسم sticky ذي خمسة مشاهد. فحوص viewport عند بداية ووسط ونهاية القسم تؤكد ظهور المحتوى وثباته؛ ليست وحدها دليلًا على فراغ أثناء الاستخدام.

## C — المحتوى والادعاءات التجارية

`publicDescription` ينظف العرض فقط، ويزيل علامات التطوير دون كتابة إلى الـAPI أو اختراع أهداف تعليمية. إفصاح HTML واضح يبين أن الكتالوج والأعداد بيانات تجربة للمنصة، وليس تبنيًا تجاريًا. أُزيلت مزايا الاسترداد غير المدعومة والاعتماد من صفحات المقرر. شهادة الإتمام مشروطة بوجود اختبار نهائي، مع شرح شرط الإكمال واجتياز الاختبار؛ ليست اعتمادًا خارجيًا أو وعدًا بإصدار تلقائي.

الـAPI العام لا يتضمن عملة: وُحّد تنسيق المبالغ بأرقام عربية دون إضافة EGP/SAR أو تحويل أو تعديل أسعار. يلزم قرار أعمال لتحديد العملة قبل البيع.

## D — تفاصيل المقرر

عنوان حقيقي ووصف منظف، رابط الدبلومة الأم من القائمة العامة، تسعير فعلي، سياق يوضح أن المقرر التابع يُسجَّل عبر الدبلومة. الحالات: غير مسجل الدخول ← الدخول؛ يملك الوصول ← متابعة التعلم؛ دبلومة مسجل فيها مع غياب الوصول ← تحديث الحالة؛ دبلومة غير مسجل فيها ← التسجيل بالدبلومة؛ مقرر مستقل ← التسجيل بالمقرر. المعالجات الأصلية لم تتغير.

أول فصل مفتوح فقط في العرض العام، مع `aria-expanded` و`aria-controls` وأزرار أصلية. عرض لوحة التحكم والمشاهدة يحتفظ بالسلوك السابق لأن `publicView` افتراضيًا false. أُزيل فيديو العينة: إن لم يوجد URL لدرس معاينة مرئي، تظهر رسالة واضحة ورابط المنهج. بيانات الدروس الحالية التي فُحصت بلا URLs فيديو؛ لا يُدَّعى نجاح تشغيل فيديو حقيقي.

## E — تفاصيل الدبلومة

العنوان والسعر وعدد المقررات والعلاقات مأخوذة من الـAPI. المساران `/diplomas/[slug]` و`/diploms/[slug]` محفوظان. زر الزائر يشرح الدخول للتسجيل، وزر المقرر يقول «تفاصيل المقرر» بدل «ابدأ التعلم». تدرج بصري أهدأ، صور أخف، ومعرض متجاوب دون تغيير التسجيل.

## F — الكتالوج

رسومات موضوعية: متصفح وبرمجة للويب، أشكال مترابطة لبايثون، أدوات تشكيل للتصميم، أعمدة ومسار للتحليل، وقوس للمعرفة العامة. اختلافات تركيبية حقيقية وليس تغيير لون فقط. الصور الحقيقية المتاحة تُحفظ، ولا صور غير مرخصة. البحث والفلاتر وروابط البرامج باقية.

## G — الجوال والتواصل

أُزيل التحكم العائم من الصفحات العامة لصالح رابط واضح في التذييل بنفس رقم واتساب ونص الرسالة الأصليين. بقي التحكم السابق خارج النطاق العام. احترام safe-area، وأزرار قابلة للتركيز، دون تغطية التسجيل أو المنهج أو الفيديو.

## H — الحركة

اختبار Chrome حقيقي عبر CDP: التمرير إلى حالات المشهد الخمس، سريع وعكسي، تمرير تدريجي، إعادة دخول القسم، تبديل المنظور، إعادة التحجيم، البديل الثابت على الجوال وreduced-motion. الخطوط الفعلية فُحصت عبر `CSS.getPlatformFontsForNode`: Alexandria للعناوين وIBM Plex Sans Arabic للنص؛ لا اعتماد على اسم CSS فقط. السكربت هو دليل قابل لإعادة التنفيذ، وليس تسجيلًا مرئيًا؛ لم يُنتَج فيديو تسجيل.

- **FAIL — دين قديم:** ESLint للملفات المراقبة 83 خطأ قبل / 82 بعد؛ تحذيرات 10 قبل / 8 بعد. الملفات المساعدة الجديدة وHeroSearchSection اجتازت focused ESLint دون أخطاء.

- **NOT TESTED:** تشغيل مقرر كامل بلا URL فيديو متاح، وبوابة دفع فعلية، واختبار قارئ شاشة بشري.

النتائج التفصيلية محفوظة دون إخفاء الفشل السابق:

- `browser-results.json`: 117 PASS / 4 FAIL في التشغيل الأول.
- `additional-browser-results.json`: 91 PASS / 4 FAIL على آخر CSS، تشمل الروابط والسعر والتجاوب والمحتوى والرجوع بالمتصفح وإعادة تركيب المشهد وثبات التمرير عند تبديل التبويب.

- `keyboard-browser-results.json`: **9 PASS / 0 FAIL** بعد تصحيح الإدخال الحقيقي وإحضار الصفحة للمقدمة؛ طي وفتح المنهج عند 1440/768/390/360 وفحص استثناءات التشغيل. لم يُضف معالج لوحة مفاتيح صوري للمكونات ولم تُضعف شروط الاختبار. النتائج القديمة تُحفظ كدليل المحاولات وتُستبدل استنتاجيًا بالفحص المخصص الناجح.

إعادة التنفيذ من مجلد الواجهة في PowerShell:

```powershell
$env:OFOQ_QA_OUTPUT='artifacts/final-polish'
$env:OFOQ_QA_POLISH='1'
node scripts/creative-rebirth-qa.mjs
```

للفحص المخصص للوحة المفاتيح في جلسة PowerShell جديدة: اضبط `OFOQ_QA_OUTPUT` كما سبق، ثم `$env:OFOQ_QA_KEYBOARD='1'` وشغّل السكربت. لا تثبيت Playwright أو تبعيات دائمة إضافية؛ يُستخدم Chrome الموجود وWebSocket المدمج في Node.

## L — الدين الفني القديم

`next.config.js` يحتوي مسبقًا على `typescript.ignoreBuildErrors: true` و`eslint.ignoreDuringBuilds: true`؛ لم تُغيَّر الإعدادات. نجاح البناء لا يعني نجاح فحص الأنواع أو lint العام. تحذيرات metadataBase وviewport/themeColor وBrowserslist القديمة باقية.

## M — موانع وقرارات أعمال

1. تحديد العملة رسميًا في العقد العام؛ لم تُفترض عملة.
2. `/checkout` صفحة قديمة غير مربوطة بالكتالوج، تعرض بيانات ثابتة ومحاكاة شراء وادعاءات استرداد واعتماد. `/checkout/[id]` محمي بالدخول لكنه يحتوي أيضًا ادعاءات اعتماد ودعم مدى الحياة وتسعيرًا قديمًا. لم تُمس لالتزام نطاق الدفع؛ لا تصلح لاعتماد تجربة بيع قبل قرار منفصل.
3. مصادر المجتمع الثلاثة أُعيد طلبها فعليًا، جميعها HTTP 404؛ `media-results.json` يسجل النتيجة. لا مصادر بديلة رسمية قُدمت، لذا لا اختلاق روابط.
4. اعتماد الحركة البشري لا يمكن استبداله بلقطات أو فحص آلي.

## N — التوصية

الصفحات العامة المصقولة مناسبة للمراجعة البصرية البشرية على `http://127.0.0.1:3004`، والباك المحلي على `http://127.0.0.1:8000`. **القبول التجاري النهائي BLOCKED** إلى أن تُحسم العملة ومسارات checkout القديمة ومصادر الفيديو، وتُراجع الحركة بشريًا. لا بدء للبوابة الجديدة أو إعادة تصميم لوحات المستخدم/الإدارة.
