# أفق — Phase 06: تجربة إدارة العمليات التعليمية

تاريخ التحقق: 10 أكتوبر 2026. النطاق: إدارة العرض التجريبي فقط. النتائج تخص نسخة محلية معزولة، وليست شهادة جاهزية إطلاق تجاري أو اعتمادًا بصريًا من المستخدم.

## A. الملخص التنفيذي

تم تنفيذ مساحة إدارة عربية متصلة ببيانات Laravel الفعلية: النظرة العامة، البرامج، المحتوى، الطلاب، الاختبارات، الشهادات والتقارير. العرض الجديد يعمل داخل DEMO_MODE، مع الإبقاء على صفحات الإدارة التشغيلية القديمة خارج هذا الوضع. لم تُعدّل واجهة الطالب أو التسويق أو الدخول أو بيانات التعليم.

الحالة: **READY FOR HUMAN VISUAL APPROVAL** في النطاق المدعوم. 112 فحص متصفح و15 فحص تفاعل PASS، دون FAIL في هاتين الدورتين. صلاحيات Bunny وبعض الوظائف الحساسة BLOCKED عمدًا. TypeScript والفحوص العامة ليست خضراء؛ التفاصيل أدناه.

للاختبار المحلي: http://127.0.0.1:3004/experience ثم اختيار الإدارة. الخادم الخلفي: http://127.0.0.1:8000/api. لا تحتاج كلمات مرور منشورة. الروابط محلية وليست نشرًا على الإنترنت.

## B. مفهوم الإدارة والقرارات البصرية

المفهوم: «مساحة إدارة» تجعل العلاقات التعليمية والأرقام قابلة للفهم، دون الإيحاء بأنها نظام مبيعات أو محاسبة. عاجي للقراءة، بنفسجي عميق للملاحة، ولمسات خضراء للحالات التعليمية. استُخدمت BrandScope والخطوط المحلية المعتمدة، دون تغيير عام للخطوط. المتصفح أثبت استخدام Alexandria للعناوين وIBM Plex Sans Arabic للنصوص العربية.

تم فصل تقدم الدروس عن الاكتمال الأكاديمي وعن حالة المحاولة. الجداول تحتفظ بأعمدتها على الهاتف داخل منطقة تمرير واضحة، بدل إخفاء البيانات. التحسينات المحدودة شملت تباين الشعار في الشريط الداكن، التفاف رابط رحلة الطالب على الهاتف، مساحة شبكة المؤشرات، ووضوح القسم النشط في الروابط الداخلية.

## D. عقود API الإدارية الفعلية

أعيد استخدام `GET /profile`، `/admin/categories`، `/admin/courses?per_page=50`، `/admin/instructors`، `/admin/reports/overview` وواجهات تقارير المستفيدين والمقررات والدبلومات والدروس القائمة.

أُضيفت ثلاثة عقود GET صغيرة لأن الواجهات القديمة لم توفر إسقاطًا مناسبًا وآمنًا لقصة العرض:

| العقد الجديد | البيانات | القيود |
| --- | --- | --- |
| `/admin/showcase/students` | id/name وأعداد التسجيلات مع البحث والترقيم | حد الصفحة 50، لا بريد أو هاتف أو تفاصيل مالية |
| `/admin/showcase/students/{student}` | التسجيلات، تقدم الدروس، الاكتمال الأكاديمي، آخر محاولة، الشهادات | يجب أن يكون الهدف طالبًا فعليًا؛ لا ملفات داخلية أو رموز تحقق |
| `/admin/showcase/exams/{course}` | الاختبار النهائي والأسئلة والخيارات وتوزيع حالات المحاولات | لا مفاتيح إجابات أو تفسيرات أو بدء محاولة |

كلها خلف Sanctum وحماية الدور، وتتحقق من دور admin في العمود وفي منظومة الأدوار. لا تمنح صلاحية للمشرف لمجرد وجوده في مجموعة middleware. الاستجابات `Cache-Control: no-store, private`. أُضيفت إلى قائمة رمز العرض بقواعد مسار دقيقة للإدارة فقط، ولم تتوسع صلاحيات بقية المسارات.

مصدر البيانات المشترك يلغي الطلبات عند تغير الصفحة/الجلسة، ولا يستخدم التخزين المؤقت القديم ذي المفتاح العام بحسب حالة تسجيل الدخول. الانتقال داخل المساحة لا يعيد جلب الكتالوج. لا أرقام أو صفوف وهمية عند فشل API؛ توجد حالة خطأ وإعادة محاولة.
